# 설정과 비밀값

## 분류

| 종류 | 예시 | 전달 방법 |
| --- | --- | --- |
| 일반 설정 | 기능 플래그, 공개 기준 URL, 로그 수준 | `env` |
| 비밀값 | API 키, 비밀번호, database Credential | `secrets` |
| 플랫폼 관리 값 | `PORT`, `DATABASE_URL`, `PAAS_DEPLOYMENT_ID`, `PAAS_STORAGE_URL`, `PAAS_STORAGE_TOKEN` | 직접 설정하지 않음 |

비밀처럼 보이는 값은 일반 설정으로 넣지 않는다. 사용자에게 분류가 불분명한 값을 받으면 비밀값으로 취급한다.

## 검증과 배포

- 로컬 env 파일을 사용하지 않는 경우 `validate_project`에는 일반 설정 값과
  `secretKeys`만 전달하고, `deploy_project`에만 필요한 비밀값을 `secrets`로
  전달한다.
- Agent가 실제 값을 로컬 env 파일로 정리한 경우 검증과 배포 모두 같은
  `localEnv.file`과 승인한 키 목록을 전달한다. 검증 요청에는 키 이름만 전송되고
  배포 요청에서만 MCP가 선택한 실제 값을 읽어 비밀값으로 전송한다.
- 비밀값 원문은 검증 요청에 전달하지 않는다.
- 비밀값을 답변, 로그, 소스 파일과 커밋에 기록하지 않는다.
- 사용자가 준 값을 확인 목적으로 되읽지 않는다.

## 세션에서 새 비밀값을 받는 경우

- 사용자가 직접 사용할 관리자 비밀번호처럼 새 값이 필요하면 용도와 입력할 내용을 먼저 설명한다.
- 사용자는 Agent 세션에 원하는 값을 입력할 수 있다.
- Agent는 앱이 이미 정한 형식 규칙만 확인하고 사용자의 값을 임의로 바꾸거나
  새 값을 대신 생성하지 않는다.
- 받은 값은 답변에서 반복하지 않고 프로젝트의 Git 제외 로컬 env 파일로 옮긴다.
- `.env.local`을 기본으로 사용하되 기존 값을 덮어쓰지 않는다.
- `.gitignore`에는 실제 env 값 파일을 제외하는 규칙을 유지한다.
- 배포 소스 압축에는 `.env`, `.env.local`, 환경별 실제 env 파일을 포함하지 않는다.
- MCP의 `localEnv`에는 파일 경로와 사용자가 승인한 키 이름만 전달한다.
- 로컬 env 파일의 다른 키는 읽거나 전송하지 않는다.

사용자에게 `.env` 사용법을 먼저 학습시키지 않는다. 필요한 이유와 어떤 값을 입력하는지만 설명하고 Agent가 파일과 배포 설정을 정리한다.

## 하드코딩 비밀값을 발견한 경우

- finding의 파일과 위치, 위험과 제안 키 이름만 설명한다.
- 기존 원문을 답변, 오류와 수정 요약에 포함하지 않는다.
- 수정 전 사용자 동의를 받는다.
- 동의하면 소스를 환경변수 참조로 바꾸고 실제 값은 로컬 env 파일로 옮긴다.
- 불확실한 일반 문자열은 자동으로 옮기지 않는다.
- 외부 Credential이 이미 Git에 기록됐다면 값 교체가 필요할 수 있다는 점만 추가로 알린다.
- 현재 파일에서 값을 제거하더라도 기존 Git 이력은 자동으로 재작성하지 않는다.
  외부에 공개된 값의 교체나 이력 정리는 별도 승인을 받은 작업으로 다룬다.

## 저장된 설정 관리

- `deployment_config`는 일반 설정 값과 비밀값 키 이름만 반환한다.
- `set_deployment_config`의 문자열 값은 추가 또는 교체다.
- `null`은 해당 키 삭제다.
- 한 키를 `env`와 `secrets`에 동시에 넣지 않는다.
- 플랫폼 관리 값은 조회만 하고 추가, 변경하거나 삭제하지 않는다.
- 설정 변경은 실행 중인 앱을 즉시 바꾸지 않는다. 같은 배포를 다시 배포한 다음 revision부터 적용된다.
- 비밀값을 교체한 뒤에는 새 revision이 정상 실행되는지 확인한다.

## 오류 처리

- 필수 키가 없으면 사용자에게 서비스 이름과 필요한 키 이름만 설명한다.
- 비밀값 형식이 잘못돼도 원문 전체를 오류 메시지에 포함하지 않는다.
- Credential이 폐기됐거나 권한이 없으면 사용자가 해당 서비스에서 새 값을 발급해야 한다고 설명한다.
